# ATLAS EAST V3.9 — Hybrid Research Foundation

هذه النسخة **تضيف بوابة فعلية لخدمة GPU خارجية اختيارية** إلى واجهة الصور الطبية؛ ولا تتضمن خادم GPU منشورًا أو نموذجًا مدرّبًا أو صلاحية تشخيص سريري. لا يعرض التطبيق تنبؤًا إذا لم تكن هناك خدمة متصلة ترجع نتائج بنموذج معروف الإصدار والمهمة ونوع الصورة.

## تشغيل الواجهة
- ارفع الملفات إلى GitHub مع الإبقاء على `app.py` في الجذر.
- في Streamlit Secrets عيّن `ATLAS_GPU_ENDPOINT = "https://YOUR-SERVICE"` و`ATLAS_GPU_TOKEN = "..."` **فقط إذا كان لديك خادم آمن متوافق**.
- لا تضع الأسرار في GitHub. لا ترسل صور المرضى دون تصريح وإزالة بياناتهم التعريفية.
- يتوقع العميل نقطة نهاية `POST /v1/infer` مع JSON فيه `modality`, `image_png_base64`, `sha256` وتوثيق Bearer. يجب أن يعيد الخادم `model_card` و`findings` و`limitations`.

## مصادر صور مرخصة (لا تُحمّل تلقائيًا)
- MedMNIST: https://medmnist.com/v2 — صور مصنفة ومقسمة للتدريب والتحقق والاختبار، **غير مخصصة للاستخدام السريري**. راجع ترخيص كل مجموعة.
- MONAI: https://project-monai.github.io/model-zoo.html — نماذج متخصصة بأوزان وإعدادات مختلفة، ولا تصلح لكل نوع صورة.
- TCIA: https://www.cancerimagingarchive.net/browse-data/ — مجموعات تصوير؛ تحقق من شروط كل مجموعة.

## تدريب بحثي تجريبي منفصل
على خادم GPU منفصل: `pip install medmnist torch torchvision scikit-learn` ثم `python train_medmnist_research.py --dataset pneumoniamnist --epochs 3`.
ينتج **مقاييس تقييم فقط**؛ لا يربط الأوزان تلقائيًا بواجهة Streamlit ولا يُعد نموذجًا سريريًا. لا تقيّم على بيانات التدريب ولا تستخدم صور الحالات التي تم التعلّم منها لاختبار التعميم.

## المصادر العلمية والحقول الأخرى
تظل وحدات `literature_intelligence.py` و`atlas_intelligence.py` للبحث في الأدبيات الطبية والهندسية والصيدلانية واستخراج القيم من النصوص. البحث لا يُثبت وجود المرض في الصورة، ولا تُرسل بيانات المرضى إلى APIs البحث.

## ما لم يُنجز
لا تنزيل لآلاف الصور في هذه الحزمة، ولا تدريب فعلي هنا، ولا نماذج متخصصة لجميع الأعضاء، ولا خدمة GPU منشورة. لا يوجد تعلم تشخيصي ذاتي من حالات غير مراجعة. لا ترفع نسخة عامة مع ادعاء كشف الأمراض بدقة مثبتة.
