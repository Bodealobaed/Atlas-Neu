# ATLAS EAST V3.4 — Federated Evidence

إضافة محرك بحث متعدد المصادر في Europe PMC وCrossref، مع إزالة التكرارات وترتيب النتائج بحسب الصلة الموضوعية وإظهار DOI والمصدر والرابط. يستخدم في الأبحاث الطبية والهندسية والصيدلانية. يعرض إخفاق مصادر البحث بوضوح ولا يختلق مراجع. لا يرسل صور المرضى أو الأسماء إلى مصادر البحث. قد تحتاج الشبكة إلى السماح باتصالات HTTPS الخارجية.

**حدود مهمة:** هذا ليس تشخيصًا طبيًا، ولا يثبت مرضًا بناء على صورة أو مقالة مشابهة. لا يوجد تدريب ذاتي تلقائي من تنبؤات النموذج، ولا نظام تقسيم تشريحي مُعتمد. للتعلم السريري الفعلي يلزم صور مرخصة ومجهولة الهوية مع تسميات مختصين ومجموعة تحقق مستقلة، وبنية تخزين آمنة. ScienceDirect يتطلب تكامل API واتفاق ترخيص بحسب صلاحيات الناشر؛ لم يُنفذ هنا.

لتشغيل الاختبارات: `python -m unittest discover -s tests` من مجلد المشروع. اضبط قاعدة بيانات دائمة باستخدام متغيرات البيئة الموجودة في V3.3، ولا تعتمد على `/tmp` للاحتفاظ بالحالات بعد إعادة نشر Streamlit.
