# ATLAS EAST V4.2 — تحسين التقسيم والواجهة

- إضافة `assisted_segmentation.py`: توسيع التحديد اليدوي بناء على اتصال البكسلات وتشابه شدتها، مع حماية ضد تحديد معظم الصورة.
- زر توسعة التحديد في `segmentation_editor.py`؛ لا يمثل تشخيصاً أو كشفاً آلياً للأمراض.
- جعل رسائل نقص إعدادات الخدمة عامة للمستخدم؛ يجب أن يضبط مسؤول التطبيق الإعدادات في Streamlit Secrets. لا تخزن المفاتيح في GitHub.
- تنبيه واضح بشأن الاستعانة بخدمة خارجية عند إرسال الصور؛ لا ترفع بيانات تعريفية دون إذن.
- إصلاح بعض تسميات الأدوات والتصدير بالألمانية والعربية.
- اجتاز 27 اختبار pytest وcompileall. لم يُجر اختبار متصفح حي لأن streamlit وstreamlit-drawable-canvas غير مثبتين في بيئة الاختبار الحالية.
- **قيد معروف**: streamlit-drawable-canvas 0.9.3 قد يتطلب فحص توافق مع إصدار Streamlit المنشور. لا توجد نماذج مرضية مدربة أو خدمة GPU فعلية في هذه الحزمة.
- إذا لم يظهر المحرر في تطبيقك: تحقق من سجل Streamlit Cloud ومن تثبيت streamlit-drawable-canvas ثم أرسل رسالة الخطأ. التوسيع يعتمد على رسم قناع أولاً.
