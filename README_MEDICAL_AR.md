# ATLAS EAST V2.8 — محطة عرض الصور الطبية البحثية

## التحديث
- بقيت أدوات تحليل المشاريع والكتب والتقارير كما هي.
- أصبح التنقل بين أقسام التحليل عموديًا في القائمة الجانبية، وكذلك الرئيسية/مساحة العمل.
- تم استبدال واجهة العتبة الطبية بعارض صور للملفات PNG/JPEG/TIFF وDICOM وNIfTI.
- أدوات التحكم: الشريحة والمحور للصور ثلاثية الأبعاد، نافذة الشدة بالنسبة المئوية، جاما، الحدة، عكس الألوان، ROI بمؤشرات X وY، تكبير ROI، إحصاءات المنطقة، مخطط توزيع الشدة، تنزيل صورة معاينة وتقرير قياسات JSON.
- لا يوجد في هذه النسخة نموذج اكتشاف أمراض أو تقسيم تشريحي مدرب؛ لا تستخدم النتائج للتشخيص.

## الخصوصية
لا يعرض البرنامج اسم المريض أو معرفه من بيانات DICOM، لكنه لا يزيل البيانات المحروقة داخل البكسلات. لا ترفع ملفات مرضى حقيقية إلى تطبيق عام دون إخفاء الهوية والالتزام بالمتطلبات القانونية والأخلاقية. الصور تبقى في ذاكرة جلسة Streamlit في هذا المسار؛ لا يتم إرسالها إلى OpenAI من قسم التصوير الطبي.

## التثبيت
ارفع جميع الملفات إلى جذر مستودع GitHub نفسه، مع إضافة `medical_workstation.py`، ثم Commit changes. لا حاجة إلى تغيير مفتاح OpenAI.

## الاختبارات المنفذة
تم فحص صياغة Python، وتشغيل اختبارات المشروع النصية، واختبار تحميل صورة PNG ومعالجة ROI محليًا. لم يتم تشغيل Streamlit Cloud في هذه البيئة؛ لا يمكن ضمان انعدام أخطاء النشر.
