# ATLAS EAST V4.0 — محرر تقسيم يدوي

- قسم Medical Imaging يحتوي محرر رسم تفاعلي بفرشاة ومستطيل ومضلع وأداة نقل، بالإضافة إلى مستطيل ROI القديم ومضلع الإحداثيات.
- يمكن تنزيل قناع المنطقة المرسومة PNG وقياس مساحة البكسلات ومساحة mm² عند توفر معايرة موثوقة.
- القناع يدوي، **لا** يكشف المرض ولا يمثل تقسيمًا آليًا معتمدًا. لا توجد في هذه النسخة ميزات 3D Slicer مثل segment editor ثلاثي الأبعاد، حفظ NIfTI mask ثلاثي الأبعاد، region growing، أو deep learning segmentation مثبت.
- يستخدم streamlit-drawable-canvas==0.9.3، وهو مكوّن طرف ثالث قد يحتاج إلى اختبار توافق مع إصدار Streamlit المستضاف. تُعاد رسم العلامات عند تغيير الشريحة؛ القناع لا ينتقل آليًا إلى بقية الحجم.
- مسارات الرسم المنحنية تعاد بناؤها تقريبيا من نقاط Fabric، لذا راجع القناع بصريًا قبل استخدامه البحثي. لا تستخدم القناع لاتخاذ قرارات طبية.
- صفحة غلاف الكتاب تعرض ATLAS EAST بخط أكبر، مع الزخرفة المتجهية الحالية؛ لا يحتوي المشروع على ملف شعار رسمي مرفق.
- النشر: ارفع الملفات إلى GitHub، أعد تثبيت requirements.txt، أعد تشغيل Streamlit. لا يلزم مفتاح API جديد للرسم اليدوي.
- الاختبارات: 21 اختبارًا برمجيًا ناجحًا. لم يُجر اختبار واجهة متصفح أو تقييم سريري.
