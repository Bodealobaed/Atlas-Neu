# ATLAS EAST V3.7 — Source-grounded book layout

هذه نسخة تطوير محدودة فوق V3.6، وليست نموذج تشخيص طبي معتمد.

- منع اعتبار كل مقطع من PDF فصلًا جديدًا مرقمًا؛ يستخدم عنوان المقطع باعتباره قسمًا ضمن الكتاب.
- إزالة فواصل الصفحات الإجبارية بين كل مقطع، لتكون القراءة متصلة.
- إزالة تكرار الجداول في ملحق آخر الكتاب، لأنها تُدرج بالفعل بجوار المقاطع ذات الصلة.
- تشديد تعليمات توليد الكتاب: توسع لغوي محدود (~15%)، دون اختلاق فصول أو نتائج أو تجارب.

البحث الطبي التلقائي الموجود في V3.6 يستخرج ملاحظات مرئية ويبحث في Europe PMC وCrossref. لا يوجد في هذا التحديث نموذج كشف أمراض مدرب، ولا يجوز اعتبار ترتيب الأوراق العلمية احتمالات تشخيصية. لتحقيق كشف مرضي موثوق يلزم نموذج لكل نوع تصوير، بيانات مرجعية موسومة، تقييم مستقل للحساسية والنوعية، ومراجعة سريرية. الصور الطبية الشخصية لا تُستخدم للتعلم الذاتي دون إذن وتدابير خصوصية.

الاختبارات المحلية لا تضمن سلامة كل ملفات PDF أو جودة المحتوى المُولد عبر API. احتفظ بنسخة احتياطية من التطبيق السابق قبل النشر.
