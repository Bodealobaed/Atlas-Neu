# ATLAS EAST V3.3 — Research Memory

أضيف محرك `longitudinal_engine.py` للذاكرة البحثية التي تخزن **ملخصات دراسات راجعها مختصون** بعد تأكيد الترخيص وإزالة البيانات الشخصية. ويمكن استرجاعها وفق كلمات البحث والمجال. توجد أيضًا واجهة لتدقيق أدلة الصور المرجعية وأبحاث PubMed دون تحويل التشابه إلى تشخيص.

- الإعداد `ATLAS_RESEARCH_DB` يحدد قاعدة SQLite. المسار الافتراضي `/tmp/atlas_east_research.sqlite3` **مؤقت** على Streamlit Cloud؛ للحفظ المستمر يجب ربط تخزين خاص دائم ومحمِي. لا تستخدم قاعدة مشتركة عامة لحالات المرضى.
- `ResearchMemory.save_model` و`list_models` واجهة برمجية لحفظ مخرجات نماذج رقمية بموافقة صريحة؛ **لم يتم ربطهما تلقائيًا** بزر النمذجة بعد، ولا يجري أي تدريب آلي من حالات غير موثقة.
- استرجاع الأبحاث يعتمد مطابقة مصطلحات قابلة للتفسير، وليس بحثًا دلاليًا طبيًا متقدمًا.
- PubMed متصل مسبقًا عبر `evidence_engine.py` عند ضغط المستخدم على البحث. **ScienceDirect غير متصل**؛ الوصول إلى النص الكامل وواجهات Elsevier قد يحتاج ترخيصًا ومفتاح API. لا يُجرى بحث سري غير موثق أو إرسال بيانات مريض.
- لا توجد نماذج مرضية مدرّبة أو معتمدة سريريًا ولا خوارزمية تقسيم آلي متخصصة. لا تفسّر درجات التشابه كاحتمالات مرض.
- اختبار: `python -m pytest -q` بعد تثبيت متطلبات التطوير.
